## Overview
Get BuildFast running locally in minutes. You'll initialize your project with the BuildFast wizard, install dependencies, set environment variables, start the dev server, and explore the default feature modules. No filtering of env values — all variables are listed explicitly here.

## Steps

- **1) Initialize the project**
Run the BuildFast wizard to create your project. It will ask for your project name.
```bash
npx buildfast
```

- **2) Install dependencies**
```bash
npm install
```

- **3) Configure environment variables**
Create a `.env` at the project root. These are required for auth, data, and payments.
```env
# Supabase
VITE_APP_SUPABASE_URL=your_supabase_url
VITE_APP_SUPABASE_ANON_KEY=your_supabase_anon_key
VITE_APP_SUPABASE_DELETE_ACCOUNT_URL=your_delete_account_url

# Stripe
VITE_APP_STRIPE_PUBLISHABLE_KEY=your_stripe_publishable_key

# Optional locale settings
VITE_APP_LOCALE_CURRENCY=USD
VITE_APP_LOCALE_DATETIME=en-US
```

- **4) Start the dev server**
```bash
npm run dev
# App runs at http://localhost:5173
```
