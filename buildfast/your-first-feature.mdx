# Your first feature

## Overview
Scaffold a new domain feature using the generator, add a route, create a page, and expose a minimal public API. This shows how the Screaming Architecture keeps features self-contained and easy to ship.

## Key Concepts
- **Plop generator:** Creates a ready-to-use feature skeleton under `src/features/<name>`.
- **Public API surface:** Export only what other features/app should use via `index.ts`.
- **Feature-local routing:** Define `paths.ts` and `router.tsx` inside the feature.
- **Side effects & data:** Keep API calls in `services/` and use React Query hooks.

## Steps

- **1) Generate the feature**
```bash
npm run plop
# Answer the prompts, e.g. name: profile
```

- **2) Review generated structure**
```
src/features/profile/
  components/
  hooks/
  pages/
  router/
    paths.ts
    router.tsx
  services/
  utils/
  index.ts  # public API
```

- **3) Define paths**
```ts
// src/features/profile/router/paths.ts
export const PROFILE_PATHS = {
  root: "/profile",
};
```

- **4) Create a page**
```tsx
// src/features/profile/pages/ProfilePage.tsx
import { Box, Heading, Text } from "@chakra-ui/react";

export default function ProfilePage() {
  return (
    <Box>
      <Heading size="lg">Your Profile</Heading>
      <Text mt={2}>Welcome to your profile page.</Text>
    </Box>
  );
}
```

- **5) Wire feature routes**
```tsx
// src/features/profile/router/router.tsx
import { RouteObject } from "react-router-dom";
import ProfilePage from "../pages/ProfilePage";
import { PROFILE_PATHS } from "./paths";

export const profileRoutes: RouteObject[] = [
  { path: PROFILE_PATHS.root, element: <ProfilePage /> },
];
```

- **6) Expose the public API**
```ts
// src/features/profile/index.ts
export { PROFILE_PATHS } from "./router/paths";
export { profileRoutes } from "./router/router";
```

- **7) Compose in the app router**
```tsx
// src/app/router.tsx
import { createBrowserRouter } from "react-router-dom";
import { authRoutes } from "@/features/auth";
import { homeRoutes } from "@/features/home";
import { settingsRoutes } from "@/features/settings";
import { profileRoutes } from "@/features/profile";

export const router = createBrowserRouter([
  ...authRoutes,
  ...homeRoutes,
  ...settingsRoutes,
  ...profileRoutes,
]);
```

## Code Examples

- **Service + React Query hook**
```ts
// src/features/profile/services/profile.service.ts
import { axiosClient } from "@/lib/axios";
export type Profile = { id: string; email: string };
export async function getProfile(): Promise<Profile> {
  const { data } = await axiosClient.get("/api/profile");
  return data;
}
```
```ts
// src/features/profile/hooks/useProfile.ts
import { useQuery } from "@tanstack/react-query";
import { getProfile } from "../services/profile.service";
export function useProfile() {
  return useQuery({ queryKey: ["profile"], queryFn: getProfile });
}
```
```ts
// src/features/profile/index.ts (add exports)
export { useProfile } from "./hooks/useProfile";
```

## Best Practices
- **Keep routes tiny:** Only map paths to pages; place data logic in hooks/services.
- **Public API discipline:** Export stable hooks/paths/routes only. Keep internals private.
- **Testing:** Unit test hooks/services with mocked HTTP and providers.
- **Naming:** Use `kebab-case` for feature folder names and consistent `PATHS` constants.
