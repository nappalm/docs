# API Communication

## Overview
BuildFast centralizes HTTP and server-state with Axios and React Query. Features define their own services and data hooks while sharing common clients and configuration from `src/lib`. This section shows how to structure requests, caching, mutations, and error handling.

## Key Concepts
- **Central Axios client:** Configure base URL, interceptors, and headers in `src/lib/axios`.
- **React Query:** Cache, refetch, and mutations with typed query keys and functions.
- **Feature services:** Keep HTTP calls in `services/` per feature; never call Axios directly from components.
- **Typed responses:** Define and export types close to services; reuse across hooks and components.
- **Env-driven config:** Use `.env` for backend endpoints and provider keys (listed below with no filtering).

## Code Examples

- **Axios client setup**
```ts
// src/lib/axios/index.ts
import axios from "axios";

export const axiosClient = axios.create({
  baseURL: import.meta.env.VITE_APP_API_BASE_URL ?? "/",
  withCredentials: true,
});

axiosClient.interceptors.request.use((config) => {
  // Example: attach auth token from Supabase or local storage if needed
  const token = localStorage.getItem("access_token");
  if (token) config.headers.Authorization = `Bearer ${token}`;
  return config;
});

axiosClient.interceptors.response.use(
  (res) => res,
  (error) => {
    // Map errors to a uniform shape if desired
    return Promise.reject(error);
  }
);
```

- **React Query client**
```tsx
// src/lib/react-query/query-client.tsx
import { QueryClient } from "@tanstack/react-query";
export const queryClient = new QueryClient({
  defaultOptions: { queries: { refetchOnWindowFocus: false } },
});
```

- **Feature service + hook**
```ts
// src/features/example/services/example.service.ts
import { axiosClient } from "@/lib/axios";
export type Item = { id: string; name: string };
export async function listItems(): Promise<Item[]> {
  const { data } = await axiosClient.get("/api/items");
  return data;
}
```
```ts
// src/features/example/hooks/useItems.ts
import { useQuery } from "@tanstack/react-query";
import { listItems } from "../services/example.service";
export function useItems() {
  return useQuery({ queryKey: ["items"], queryFn: listItems });
}
```

- **Mutations**
```ts
// src/features/example/hooks/useCreateItem.ts
import { useMutation, useQueryClient } from "@tanstack/react-query";
import { axiosClient } from "@/lib/axios";
export function useCreateItem() {
  const qc = useQueryClient();
  return useMutation({
    mutationFn: async (input: { name: string }) => {
      const { data } = await axiosClient.post("/api/items", input);
      return data;
    },
    onSuccess: () => {
      qc.invalidateQueries({ queryKey: ["items"] });
    },
  });
}
```

- **Error handling pattern**
```ts
// src/shared/services/http-error.ts
export type HttpError = { status?: number; message: string };
export function toHttpError(e: unknown): HttpError {
  if (typeof e === "object" && e !== null && "response" in e) {
    const anyErr = e as any;
    return { status: anyErr.response?.status, message: anyErr.response?.data?.message ?? "Request failed" };
  }
  return { message: "Unexpected error" };
}
```

## Environment Variables (no filtering)
```env
# Backend base URL (optional; defaults to "/")
VITE_APP_API_BASE_URL=https://api.example.com

# Supabase
VITE_APP_SUPABASE_URL=your_supabase_url
VITE_APP_SUPABASE_ANON_KEY=your_supabase_anon_key
VITE_APP_SUPABASE_DELETE_ACCOUNT_URL=your_delete_account_url

# Stripe
VITE_APP_STRIPE_PUBLISHABLE_KEY=your_stripe_publishable_key

# Locale (optional)
VITE_APP_LOCALE_CURRENCY=USD
VITE_APP_LOCALE_DATETIME=en-US
```

## Best Practices
- **Keep services thin:** Map HTTP <-> types; avoid UI logic.
- **Stable query keys:** Use arrays with clear namespaces, e.g. `["profile", id]`.
- **Co-locate types:** Export types from services; import into hooks/components.
- **Invalidate precisely:** Prefer `invalidateQueries` with specific keys after mutations.
- **Avoid over-fetching:** Leverage `staleTime`, `select`, and dependent queries.
