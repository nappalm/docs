## Overview

BuildFast comes with Stripe integration pre-configured, allowing you to accept payments and start generating revenue from day one. We handle the Stripe setup so you can focus on building your product features instead of wrestling with payment infrastructure.

## Key Features

### Pre-Configured Setup

Stripe is already integrated and configured in BuildFast. You just need to add your publishable key to start accepting payments. The entire payment flow infrastructure is ready to use.

### Client-Side Components

BuildFast uses `@stripe/react-stripe-js` for secure, PCI-compliant payment UI components. All sensitive payment data is handled securely by Stripe, keeping your application compliant.

### Revenue Ready

Start accepting payments immediately after configuration. Whether you're building a SaaS product, subscription service, or one-time purchase flow, Stripe integration enables you to monetize your application quickly.

### Secure by Default

Only publishable keys are used on the client side. All secret operations are handled securely through your backend, following Stripe's security best practices.

## Implementation

### Stripe Client Setup

The Stripe client is configured in the lib directory:

```ts
// src/lib/stripe/index.ts
import { loadStripe } from "@stripe/stripe-js";

export const stripePromise = loadStripe(
  import.meta.env.VITE_APP_STRIPE_PUBLISHABLE_KEY!
);
```

### Stripe Elements Provider

Wrap your payment components with the Stripe Elements provider:

```tsx
// src/features/payments/StripeProviders.tsx
import { Elements } from "@stripe/react-stripe-js";
import { stripePromise } from "@/lib/stripe";

export function StripeProviders({ children }: { children: React.ReactNode }) {
  return <Elements stripe={stripePromise}>{children}</Elements>;
}
```

### Checkout Form Example

Create payment forms using Stripe's pre-built components:

```tsx
// src/features/payments/components/CheckoutForm.tsx
import { CardElement, useElements, useStripe } from "@stripe/react-stripe-js";
import { useState } from "react";
import { Button } from "@chakra-ui/react";

export function CheckoutForm() {
  const stripe = useStripe();
  const elements = useElements();
  const [loading, setLoading] = useState(false);

  const handleSubmit = async (e: React.FormEvent) => {
    e.preventDefault();
    if (!stripe || !elements) return;

    setLoading(true);

    try {
      // Call your backend to create a PaymentIntent
      const { clientSecret } = await fetch("/api/create-payment-intent", {
        method: "POST",
        headers: { "Content-Type": "application/json" },
        body: JSON.stringify({ amount: 2000 }), // $20.00
      }).then((r) => r.json());

      // Confirm the payment with Stripe
      const { error } = await stripe.confirmCardPayment(clientSecret, {
        payment_method: {
          card: elements.getElement(CardElement)!,
        },
      });

      if (error) {
        console.error("Payment failed:", error);
      } else {
        console.log("Payment succeeded!");
      }
    } catch (err) {
      console.error("Error:", err);
    } finally {
      setLoading(false);
    }
  };

  return (
    <form onSubmit={handleSubmit}>
      <CardElement />
      <Button type="submit" disabled={!stripe || loading} mt={4}>
        {loading ? "Processing..." : "Pay $20.00"}
      </Button>
    </form>
  );
}
```

### Subscription Management

Handle recurring subscriptions with Stripe:

```tsx
// src/features/payments/components/SubscriptionButton.tsx
import { useStripe } from "@stripe/react-stripe-js";
import { Button } from "@chakra-ui/react";

export function SubscriptionButton({ priceId }: { priceId: string }) {
  const stripe = useStripe();

  const handleSubscribe = async () => {
    if (!stripe) return;

    // Redirect to Stripe Checkout
    const { error } = await stripe.redirectToCheckout({
      lineItems: [{ price: priceId, quantity: 1 }],
      mode: "subscription",
      successUrl: `${window.location.origin}/success`,
      cancelUrl: `${window.location.origin}/cancel`,
    });

    if (error) {
      console.error("Checkout error:", error);
    }
  };

  return <Button onClick={handleSubscribe}>Subscribe</Button>;
}
```

## Configuration

### Environment Variables

Add your Stripe publishable key to your `.env` file:

```env
# Stripe
VITE_APP_STRIPE_PUBLISHABLE_KEY=pk_test_your_publishable_key_here
```

### Backend Integration

Create a backend endpoint to handle PaymentIntent creation securely:

```ts
// Example backend endpoint (Node.js/Express)
app.post("/api/create-payment-intent", async (req, res) => {
  const { amount } = req.body;

  const paymentIntent = await stripe.paymentIntents.create({
    amount,
    currency: "usd",
  });

  res.json({ clientSecret: paymentIntent.client_secret });
});
```

## Best Practices

- **Keep Secrets Server-Side** - Never expose secret keys in client-side code
- **Use Payment Intents** - Always use PaymentIntents API for card payments
- **Handle Errors Gracefully** - Provide clear error messages to users
- **Test Thoroughly** - Use Stripe's test mode before going live
- **Webhook Handling** - Set up webhooks to handle payment events securely
- **Idempotency** - Use idempotency keys for critical operations
- **Localization** - Support multiple currencies and languages for global reach
